
 <h1>AI Email Generator<h1>
An AI-powered web application that generates professional emails using Google's Gemini AI and Streamlit.
<h3>Features</h3>
   <ul>
<li>Generate professional emails with AI</li>
     <li>Multiple email types</li> 
     <li> Multiple writing tones</li>
      <li>Short, medium, and detailed email lengths</li>
      <li>Custom recipient and purpose </li>
      <li>Additional details support</li>
      <li>Editable generated email </li>
     <li> Download generated email as a text file </li>
      <li>Simple and responsive Streamlit interface</li>
     </ul>
   <h3>Technologies Used</h3>
   <ul>
   <li> Python </li>
    <li> Streamlit </li>
    <li> Google Gemini API </li>
    <li> Google GenAI SDK </li>
   </ul>
